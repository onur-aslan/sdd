# Workflow: Feature Frontend Development

> Generated by workflow-gateway

## Steps

```
/clear
/sdd:deep-spec @<what you want>
/sdd:spec-to-prd
```

→ **Human review** — Check spec, handle open questions, approve PRD

→ Check PRD size: [small PRD](#small-prd) | [large PRD](#large-prd)

## small scope

```
/clear
/implementer @<prd-path>
```

(optional) Verify:
```
/sdd:verify-with-playwright-mcp
```

→ **Human review** — Verify implementation and verification

## large PRD

```
/sdd:prd-to-task @<prd-path>
```

→ **Human review** — Check task breakdown in feature.md

```
/clear
/sdd:feature-implementer @<feature-path>
```

→ **Human review** — Verify implementation

## verify all (at the end)

```
/clear
/sdd:feature-e2e-verifier @<prd-path>
```

→ **Human review** — Approve E2E verification

(optional)

## optional (all at the end)

PRD test writer (for acceptance tests):
```
/sdd:prd-test-writer @<prd-path>
```

→ **Human review** — Approve acceptance tests

Gap analysis:
```
/sdd-utilty:gap-analysis
```

→ **Human review** — Review gaps, approve fixes

Code slop review:
```
/sdd-utilty:code-slop-review
```

→ **Human review** — Review findings, decide what to fix
